# Decisions on open questions (increment 1)

Answers to the product owner's open questions, approved by the user with "use your picks".

1. Desktop widths to verify: 1280, 1366 and 1920 px.
2. Browsers: current Chrome and current Microsoft Edge on Windows. Other browsers are out of scope.
3. 4-suit deals: the bank holds between 4 and 10 stored winnable deals (user update). It currently holds 7: seeds 8, 10, 13, 15, 46, 97 and 99. Seed 46 is kept. Growing the bank further is a later increment, and the builder must resume rather than overwrite.
4. Settings extras (Light/Dark interface option and saving settings in localStorage): keep.
5. Small screens below 600 px: not a requirement for increment 1. The existing media query stays as is.
6. Automated browser tests: not in increment 1. Browser checks are manual, using a checklist.
7. Opening the game: must work from a file path and from a local server.

Rules that apply: none beyond the Spider Solitaire brief. Do not add offline, touch-target, phone or other rules from other projects.
